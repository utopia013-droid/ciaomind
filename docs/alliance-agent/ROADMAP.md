# 联盟协作代理：开发路线

2026-10-25 确认方向：依据公开能力独立实现，主代理负责架构、调度和交叉验收。任务入口：[ciaomind #6](https://github.com/utopia013-droid/ciaomind/issues/6)。本路线不预设交付日期，按验收结果推进。

## 第一阶段：可靠任务底座

交付本地 CLI、SQLite 任务与事件、确定性路由、JSON 文件任务包，以及带输入指纹的结果回读。加入独立审查规则；合成任务可在无模型凭据时运行。

推进到下一阶段前，需留下可重复验证的证据：

- 任务、结果和事件在关闭并重新打开数据库后仍存在。
- 相同输入重复创建、重复派发不产生额外执行；冲突输入明确失败。
- 错误输入摘要、过期派发轮次和不匹配产出者的结果均被拒绝。
- 产出者自验收失败；不同审查者可完成一次合成任务闭环。
- 代码检查与实际测试结果写入 PR，另一代理或人复核。

此阶段不把合成结果称为真实模型输出，不把进程曾启动称为后台常驻。

## 第二阶段：接入一个真实工人

选择用户已经授权的一名工人，把第一阶段的文件契约接入其实际执行环境。Eve 负责智能体适配；任务协议继续独立于模型和提供方。先验证一个小任务，再决定扩展连接。

验收任务使用合成数据完成“领取 → 执行 → 提交结果 → 另一代理复核”。需记录实际工人身份、环境、任务及输入指纹、产出与验证结果；仅有 SDK 配置或本地身份字段不能证明远端身份。若接 GitHub 写回，限定仓库与任务分支，产出进入 PR，由人按现有流程合并。

外部模型调用需先确定可用凭据、调用权限和预算；ChatGPT 订阅不作为 API 授权证据。连接缺失时记录阻塞，不自动购买、升级或切换到未经授权的提供方。

## 第三阶段：常驻协作

在前两阶段的真实证据上加入定时检查、暂停恢复、失败重试、有限任务记忆和成本记录。首个候选用途是读取指定 Issue 与看板，生成附来源的进度报告；对外发送报告另行授权。

验收需覆盖跨进程重启恢复、重复触发不重复领取、暂停阻止新任务、失败重试有上限，以及无权限或预算不足时进入可见的阻塞状态。若承诺常驻，须提供目标运行环境的实际运行与恢复记录。

个人原文与长期私人记忆仍保存在私有资料源，只向任务提供必要片段。记忆检索、主动研究和电脑操作分别设验收，不从调度闭环推定这些能力已可用。

## 当前状态与下一步

首阶段已实现，14 项测试、类型检查、构建及独立代码复核通过；另完成当前会话内两个独立代理的手动文件交接验收。具体证据见 [VERIFICATION.md](VERIFICATION.md)。这没有建立自动工人适配或真实 Eve 模型调用，第二阶段仍需按其标准继续验证。主代理汇总任务与依赖，工人各自交付，独立复核后再更新状态。

官方 Dots 启用方案不再阻塞开发；历史 [openclaw-space PR #25](https://github.com/utopia013-droid/openclaw-space/pull/25) 不作为本路线的完成项。详细边界和来源见 [DESIGN.md](DESIGN.md)。
