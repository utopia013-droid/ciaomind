# 联盟长期目标总控：交付与后续路线

2026-10-25 确认按方案直接生成，由主代理负责架构、分工和交叉验收。任务入口：[ciaomind #6](https://github.com/utopia013-droid/ciaomind/issues/6)。按证据推进，不预设“全部能力已经接通”。

## 已生成：两层本地总控

- Director 接收自然语言主旨与验收，不要求用户手写步骤；保存规划、独立计划审查、子目标执行、原主旨验收及有上限的重规划状态。
- Coordinator 推进依赖步骤，保存租约、输入摘要、轮次、调用预约、结果和独立审查；支持暂停、恢复、有限重试与只读维护。
- 提供 Codex CLI、Gemini headless 适配及明确的本地 demo，真实工人默认关闭；提供命名空间范围检查和十个 Eve 管理工具。
- 提供 CLI、常驻轮询和 systemd 用户服务模板；模板只生成，未安装或启动。

离线 demo 能验证程序连续推进、重开恢复和固定合成计划。它没有证明真实模型理解了任意目标。详细实测、测试命令与提交以 [VERIFICATION.md](VERIFICATION.md) 为准；操作步骤见 [OPERATIONS.md](OPERATIONS.md)，契约见 [PROTOCOL.md](PROTOCOL.md)。

## 下一关：真实认证与单工人闭环

当前 Codex CLI 的 ChatGPT 登录元数据不等于推理授权：最小真实只读探针返回 HTTP 401 / `AUTH_REQUIRED`。先沿官方支持的账号与运行配置核实认证、工作区、提供方与可用额度；不反复盲试、不自动购买或转入 API key 计费。

修复后使用合成、只读的小主旨，留下规划、计划审查、实际工人结果、原主旨验收与输入指纹记录。不同工作进程或本地角色标签不能单独证明远端身份。需分别汇报工人连接与 Eve 对话模型连接，不把其中一个成功推定为另一个成功。

## 再接第二家与目标主机

第二家提供方应使用自己明确授权的接口、凭据与允许范围。Gemini 当前尚无真实安装/认证回执；接入后先验证一次真正跨厂协同、意见分歧处理与失败改派，不能用 demo 或同一厂家的另一个标签充数。

选定用户掌握且持续在线的主机，配置私有持久磁盘和单一调度 owner；由操作者安装相应服务。验收覆盖一次进程中断、一次工人失败及一个真实阻塞，证明无人输入“继续”仍能推进，重启不重复副作用，暂停能阻止后续领取，预算与周期不会悄悄扩充。

已知阻塞应写明缺失条件、已试方法及复查时点，继续推进其他无依赖目标。必须由用户决定的事项集中成可选择的决策包，避免每个正常步骤反复要求确认。

## 最后扩展：个人生活、写入与受控升级

以清楚的结果指标逐一加入个人生活和主旨项目。个人原文与长期私人记忆留在私有资料源，只向执行步骤提供必要片段；命名空间逻辑分开之外，还要按实际风险选择独立凭据、进程与数据目录。

当前 autonomous mission 限于只读。新增仓库写入、应用操作、外联或其他有副作用能力前，明确资源范围、预授权、幂等与结果不明时的核对流程；不通过换模型扩大权限。生成改进分支后保留固定评测、不同产出者的审查、有限试运行和回滚证据，主旨、授权与验收仍由用户掌握。

官方 Dots 启用不再是依赖，旧 [openclaw-space PR #25](https://github.com/utopia013-droid/openclaw-space/pull/25) 只保留历史参考。生产完成的标准是持续取得可核验的目标进展，不是运行更久、生成更多报告或让更多模型互相同意。
